## Admin Management Module

This module handles all operations related to administrator.

## Features:
- Create, Read, Update and Delete (CRUD) admin users
- Validate credentials and change passwords
- Bootstrap-styled User Interface
- Alerts for success/error messages

## CRUD Methods:
- createAdmin() - Create
- getAllAdmins(),getAdminByUsername() - Read
- updateAdmin() - Update
- deleteAdmin() - Delete(Currently login admins)

## Technologies 
- Java
- JSP
- Bootstrap
- HTML/CSS/JavaScript
- Intellij IDEA Ultimate
- Tomcat Server 9.0.100
